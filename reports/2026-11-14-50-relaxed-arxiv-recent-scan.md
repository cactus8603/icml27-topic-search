## 3. 候選 A：選擇性泛化防禦（inoculation 家族）的漏出預測與修正 —— 信心：中

### 一句話題目

Inoculation 類防禦（IP、NIP、inoculation adapter、PPS、gradient routing）只有在訓練把模型的「無提示行為」也推向該特質時才會漏出；本題要在訓練前就預測漏出程度，並用一個針對無條件漂移的修正項把漏出壓下去。

### 為什麼是現在

- 原始兩篇（2510.04340 Tan et al.；2510.05024 Wichers et al.）是 2025-10。Anthropic 在生產級 RL 用了 IP（2511.18397）。據 2611.04260 的引文〔全文〕，Anthropic 的風險報告也描述了 IP 用在 Claude Opus 4.6 與 Claude Mythos Preview 的訓練。
- 之後一年約 10 篇方法跟進：
  - 2606.30252 inoculation adapters
  - 2607.18639 token inoculation（NeurIPS 2026）
  - 2609.15886 inoculation midtraining
  - 2609.35356 stratified IP
  - 2611.04260 neologism IP
  - 2610.17062 gradient routing in RL（只從引文得知）
  - 2512.19027 recontextualization（只從引文得知）
- 機制面只有一篇：2604.16423〔全文〕。
- 方法很多，但「什麼時候會漏、能不能事先預測」仍明確開著：
  - 2604.16423 自述「對 inoculation prompting 的滿意理解仍是重要的開放問題」〔全文〕。
  - 2611.04260 的限制段說：「在窄任務上結果取決於訓練哪個 token……我們找不到事先選擇的可靠方法」，並指出「微調越把模型的正常行為推向特質，漏得越多（Fig. 20）」〔全文〕。

### 切入角度（可當貢獻）

1. **漏出的理論模型**：用兩條路徑的特徵模型（受 inoculation context 條件化的路徑，加上共享的無條件路徑）推導出一個預測：漏出量約等於特質梯度落在無條件路徑上的比例。這把下面兩篇的觀察放進同一個量裡：
   - 2604.16423 的 step-0 梯度餘弦與「IP 降低特質 token 損失」；
   - NIP 的「漏出追隨漂移」。
2. **訓練前的預測量**：在 step 0 或很少幾步內計算這個量。這也直接回答 NIP「事先選 token」的開放問題。驗證範圍是 6–10 種防禦、3–4 個任務：用秩相關預測漏出。
3. **修正方法**：在 inoculation 訓練中加入只作用於特質相關 token 的無條件錨定項。具體可以是無提示前向下的 KL 錨定，或把預測出的無條件分量投影掉。目標是在不損失目標能力的前提下降低漏出。
4. **評估框架**：借用 2611.12864 的 on-the-line 圖。好的防禦應該把模型移到線外（同樣的 in-domain 能力、更低的 OOD 特質），只把模型沿線推動不算數。這能避免「只是學得少」這種假改善。

### 最接近的工作與區隔

| 論文 | 內容 | 區隔 |
|---|---|---|
| 2611.04260 NIP〔全文〕 | 學一個新 token 取代英文 inoculation 提示，防止使用者打回特質 | 它解決「被打回」，漏出量與其他方法相當；選 token 無法事先判斷。本題做漏出預測與修正 |
| 2604.16423 Shifting the Gradient〔全文〕 | IP 和 PPS 的行為與機制比較，只用 Qwen2.5-7B 和 evil 特質 | 本題給可預測的定量理論與方法，不只做描述 |
| 2609.35356 Stratified IP〔摘要〕 | 只對含不良行為的子集加 inoculation，縮小 backdoor 觸發 | 這是啟發式方法；本題提供它何時有效的理論，並當作基線 |
| 2611.12864 Persona 可預測性〔摘要〕 | ID 與 OOD persona 率呈 probit 線性 | 本題拿它當評估工具，問題是防禦能否離線 |

### 最強反駁與回應

- **反駁 1：方法已經很多，這只是又一個變體。**
  回應：主貢獻放在預測量與理論，方法是理論的推論。投稿定位是「理解加上可用工具」，符合使用者「不必贏 SOTA」的放寬。
- **反駁 2：LLM 評審量 EM 很吵，結論可能是評估假象。**
  回應：
  - 採用 2611.08569 的分解式 EM 基準和 Dubiński 等人的評審設定；
  - 同時報告可程式判定的特質（全大寫、語言、MBPP reward hack 的測試作弊），這部分不需要評審。
- **反駁 3：MATS 與 Anthropic 的團隊產出很快，1 月前可能撞題。**
  回應：這是真風險，所以只給「中」。區隔要靠可證偽的定量預測，而不是再出一個新防禦。
- **反駁 4：只在 LoRA 和 7B 以下成立。**
  回應：2611.10397 指出 LoRA 和正則化會放大潛意識轉移，可訓練參數集合本身就是變因。把它當成實驗軸（LoRA 秩、全參數微調）正面處理，反而能測試理論。

### 前兩週停損實驗（GPU 小時全為〔推估〕）

- **設定**：
  - 模型：Qwen2.5-7B-Instruct 與 Qwen3-4B，LoRA。
  - 任務：Betley EM 三組窄資料集（醫療、理財、極限運動）；MBPP reward hack；一個可程式判定的玩具特質（全大寫或西班牙文）。
  - 防禦：無防禦、IP、改寫 IP、NIP（作者有附程式則直接用）、PPS、stratified IP，共 6 種；2 個 seed。
- **成本**：每次 7B LoRA 微調加評估生成約 0.5–0.8 GPU 小時，約 70 次，合計 **約 40–55 GPU 小時**。在 4 張 H200 上大約 3–4 天。
- **停損判準（事先寫定）**：
  - step-0 預測量和最終漏出（無提示特質率減去無防禦基線）的 Spearman 相關要 ≥ 0.6，且至少 3 個任務中有 2 個成立。不成立就停。
  - 修正項在至少 2 個任務上要讓漏出相對下降 ≥ 30%，且目標能力損失 ≤ 3 個百分點。不成立就把題目降為純理解型，再評估是否值得繼續。

### 信心：中

- 加分：方向熱、ICML 會收對齊與安全的方法加理解型論文；跟進數在甜蜜區；計算便宜；開放問題有原文明寫。
- 扣分：與 MATS 系列撞題的風險高；評估雜訊大；理論模型可能過度簡化。
- 升到中偏高的條件：前兩週的停損判準通過。

## 4. 候選 B：潛意識學習（subliminal learning）的統一轉移預測量與投影防禦 —— 信心：中偏低

### 一句話題目

用「教師—學生 logit 差在學生可訓練切空間上的投影」這一個量，統一解釋為何軟標籤只要幾百筆就夠、硬標籤要上萬筆，以及為何 LoRA 和正則化反而放大轉移；再用投影法做防禦。

### 現況〔摘要〕

10 週約 20 篇，樣本內 24 篇〔推估〕。其中：
- **機制與理論**：
  - 2609.01091 trait-direction drift（NeurIPS 2026）
  - 2609.23260 kernel 觀點
  - 2610.04907 noisy inverse 觀點：軟監督幾百筆即可近乎完整還原 steering 向量
- **反直覺現象**：
  - 2611.10397 正則化與 LoRA 放大轉移，全參數微調反而通常沒有
  - 2611.10110 homeopathic learning
  - 2611.02509 balloon effect
- **防禦**：
  - 2609.22215 liminal training
  - 2610.13536 只從參數更新做無監督發現與投影
  - 2609.20027 資料歸因過濾不可靠
- **擴展**：
  - 2610.41301 透過 RL 評審分數轉移
  - 2611.08538 VLM
  - 2610.30884 跨預訓練 checkpoint

### 切入角度

1. 一個可在訓練前算出的轉移係數，同時解釋 hard 對 soft、LoRA 對全參數、資料量三條軸。目前三篇理論各自只解釋一條軸。
2. 由係數導出「切空間投影防禦」，和 2610.13536 的事後投影比較。
3. 預測量用到 OPD（軟、on-policy）設定。

### 最接近的工作與區隔

- 2610.04907 與 2609.23260 各自只處理 hard／soft 或單一機制。
- 2611.10397 是現象報告，沒有預測理論。
- 2610.13536 的防禦需要多個教師資料集。

### 最強反駁

10 週 20 篇，理論已有三篇。審稿人會說「第四個解釋」。

回應：只有在統一預測量能定量預測 2611.10397 的反直覺結果時，才有新意。這點要第一週驗證。

### 前兩週停損

- Qwen2.5-1.5B／7B，數字序列加動物偏好的標準設定。
- 測 hard／soft × LoRA 秩 {8, 64, 全參數} × 3 種資料量，看預測量是否能排序轉移強度。
- 成本約 **25–35 GPU 小時**〔推估〕。
- 停損：秩相關 < 0.6，或無法重現 2611.10397 的「全參數微調無轉移」。

### 信心：中偏低

方向熱，但擁擠度接近使用者「佔滿」的界線。

## 5. 候選 C：漂移模型（Drifting Models）在「每個條件只有一個正樣本」時的條件生成 —— 信心：中偏低

### 一句話題目

Drifting 在條件只有單一樣本時會塌到一個殼層上（DriftingPlanner 明寫了這個現象）。本題給出統一的條件漂移場估計，例如條件空間核平滑或聯合分佈漂移，並證明它的平衡點正確。

### 現況〔摘要〕

- 原文是 2602.04770（Deng, Li, Li, Du, He；ImageNet 256 一步生成，FID 1.54）。
- 2026-02 以來約 55 篇相關（arXiv 查詢清單，含少量雜訊〔推估〕），包括：
  - **理論**：可辨識性、非保守場、有限粒子收斂率、子取樣偏差修正、與 score 統一、多尺度（2609.15193）、UOT（2609.32708、2610.18552）、判別幾何（2610.04703）
  - **文字**：Seq-Drifting 2610.12879、ReLaDrift 2610.23225
  - **條件設定**：Keyed drift fields 2603.14056、block-triangular joint drifting 2609.26435、Implicit drifting policy 2606.01098
- 2611.01283 DriftingPlanner〔摘要〕明寫：「計算每個場景的場只會留下單一正樣本，互斥讓生成軌跡落在專家軌跡周圍的殼層上。」

### 切入角度

- 條件漂移的平衡點分析：單一正樣本時的偏差。
- 條件空間核加權，或用聯合分佈的漂移場推導統一估計，並證明一致性。
- 驗證成本低：2D 玩具、條件高斯混合、CIFAR 帶連續條件、軌跡資料。

### 最接近的工作

- 2609.26435 已用聯合分佈處理動態系統。
- 2603.14056 keyed drift fields。
- 2611.01283 的每場景修正。

### 最強反駁

全年約 55 篇，條件版已有至少三種解法；Kaiming He 團隊也可能自行處理文字到影像的版本。

### 前兩週停損

- 玩具加 CIFAR-10 條件實驗，約 **20–30 GPU 小時**〔推估〕。
- 停損：統一估計在單一正樣本時不能明顯勝過 2609.26435 的作法。

### 信心：中偏低

方向好、ICML 會收，但已擁擠。

## 6. 候選 D：RL 後訓練的訓練—推理數值不一致，統一成「偏差加延遲」的修正 —— 信心：中偏低

### 一句話題目

把 bf16 捨入造成的權重黏滯、引擎數值差、非同步延遲放進同一個策略梯度偏差模型，導出隨訓練階段調整的修正。

### 現況〔摘要〕

- **bf16 捨入吃掉 RL 更新**這個核心問題，已有兩篇幾乎同時做掉：
  - 2610.41073 Fair Cast：Qwen3-1.7B 每步只有 0.4–0.5% 的服務權重改變，rollout 策略落後 50–150 步；修法是隨機捨入或 error feedback。
  - 2611.13545（Blankevoort 等）：隨機捨入補上 BF16 與 FP16 的收斂差距。
- 不一致來源的拆解：
  - 2610.40945：把誤差拆成數值差與策略延遲，指出兩者需要不同修正。
  - 2610.32951：捨入位置對齊。
  - 2609.32444：校準重要性取樣（CIS）。
- 低精度 RL：
  - FP4 RL 至少 4 篇（2611.04887、2611.04376、2610.07767、2610.07043）。
  - MXFP8 RL：2610.34915。

### 切入角度

統一偏差模型，並推出「捨入方式 × 重要性權重截斷」的聯合設計。這和 2610.40945 的空間重疊很大。

### 最強反駁

核心修正已發表，剩下的統一是增量。另外 H200 不支援原生 FP4，FP4 部分只能模擬。
