# 「Focus and Dilution」延伸題：撞題查核與可行性評估（2026-11-14）

**一句話結論**：截至今天，沒查到有人把 focus–dilution 延伸到多頭、兩層或 LayerNorm（以下簡稱 LN）的論文。不過原作者群在這條線上很活躍，同時間做同題的風險不低。三個方向裡，非理論專業者在 10 週內最有機會的是「加 LN」，前提是先用不到 20 GPU 小時的停損實驗確認現象確實存在。

## 1. 原論文 2605.01199（已讀 arXiv HTML 全文；附錄 E 用本機解析 HTML 取得原文）

1. **作者與會議**：Zheng-An Chen、Pengxiao Lin、Zhi-Qin John Xu、Tao Luo，上海交大。arXiv 的 comment 欄寫「ICML 2026 spotlight」，ICML 網站則同時有 oral 頁（icml.cc/virtual/2026/oral/71193）和 poster 頁。兩者不一致；oral 頁的標題我只在搜尋結果裡看到，沒有點開確認。
2. **資料**：一階馬可夫鏈，轉移矩陣 P = λI + (1−λ)1πᵀ。π 裡有一個高頻 token，其餘低頻 token 對稱；另加一個大小為 δ 的擾動來打破對稱。只預測最後一個 token。
3. **模型**：單層單頭，`f = softmax(Z W_Q W_Kᵀ Zᵀ) Z W₁`，其中 Z = E_X W₀。沒有獨立的 V 矩陣，也沒有殘差、LN 或位置編碼。
4. **損失與最佳化**：最後一個 token 的交叉熵，取母體極限（N 和序列長度都趨近無限）。分析用連續梯度流，不處理離散步。
5. **初始化**：每個參數 i.i.d. N(0, ε²)，ε 很小。整套結果依賴這個小初始化。
6. **定理 3.2（凝聚）**：W₀ 和 W₁ 在 Θ(log 1/ε) 時間內對齊成秩一結構，W_Q、W_K 則停在 O(ε)，因為在原點 ∂L/∂Φ = 0。這條是改寫自 Chen & Luo 在 NeurIPS 2025 的前作 2510.06954。
7. **定理 3.5（聚焦）**：在鞍點 θ_c¹ 附近，唯一不穩定的方向落在注意力參數上，注意力因此集中到高頻 token。
8. **定理 3.7（稀釋）**：在秩一不變流形上，γ₁ 和 γ_{i≠1}（各 token 嵌入在該方向上的幅度）的加權差以 exp(ct) 成長，等於嵌入的「質量」被重新分配，稀釋了先前的聚焦。
9. **定理 3.9（新方向）**：δ 擾動解開退化臨界點。切向不穩定性至多 O(δ²)，法向有 Θ(δ) 的不穩定特徵值，下一輪循環由此展開。這一條只對 d = 3 證。
10. **證明技術**：
    - 在鞍點附近逐段線性化，用常數變易法加 bootstrap 控制誤差；
    - 化約到不變流形；
    - 用 Lyapunov–Schmidt 處理退化 Hessian；
    - 用馬可夫遍歷性推出母體梯度。
11. **實驗規模**：嵌入維度 m = 256，詞彙 d 很小，π 按 1/2ᵏ 指數衰減，λ = 0.8，序列長 20，10 萬條序列，Adam lr = 1.5e-4，初始化 N(0, 1/m²)。真實資料用 WikiText 和 TinyStories，模型相同，只訓練 1 個 epoch。
    - 理論是梯度流，實驗卻用 Adam，兩者不一致，這點可以被質疑。
    - 沒找到程式碼連結，也沒寫 GPU 時數。

## 3. 可行性

**(a) 多頭**
- 每個頭在原點的 ∂L/∂Φ_h 都是 0。進入聚焦階段時，不穩定方向對每個頭相同（同一個 α₁），所以不穩定子空間會退化成 H 維。
- 「各頭同步聚焦到同一個高頻 token」幾乎能照原定理 3.5 直接推廣，容易證，但貢獻小。
- 「何時、如何分工」要做二階或對稱破缺分析，難度接近原論文的 Lyapunov–Schmidt 段落；而且 A 已經講過「先競爭、後合作」。

**(b) 兩層**
- 第二層的輸入是第一層的 softmax 混合。母體梯度要對馬可夫鏈取 softmax 乘積的期望，臨界點也沒有封閉解；若再加殘差，不變流形還得重找。
- 這是三者中最難的。10 週內非理論背景不建議碰。

**(c) 加 LN**
- **根本難點**：LN 不受尺度影響。即使參數很小，LN(EW₀) 仍是 O(1)，原論文「一切都是 O(ε)」的小初始化線性化在嵌入端會失效，需要重新建立凝聚階段。
- **好消息**（以下是我的推導，沒在文獻裡看到，也還沒驗證）：
  - 在秩一流形 W₀ = γαᵀ 上，LN 會把每個 token 的嵌入壓成 ±（同一個正規化向量），只剩 γ_i 的正負號，幅度資訊消失。
  - 原論文的聚焦（依頻率分出 token 1）和稀釋（定理 3.7 的 γ 幅度重新分配），兩者靠的都是 γ 的幅度。
  - 因此可以猜：有 LN 時，秩一階段的聚焦和稀釋會被壓制，要等嵌入秩升到 2 以上才會出現。
- 這是一個可以寫成「乾淨命題」的反直覺預測，證明大多是代數加原論文定理的改寫。我認為這是非理論專業者 10 週內最有機會的方向。
- 要注意：學習式的 gain／bias、LN 放在哪裡、centering 怎麼做，都會改變結論，必須先固定一個最簡設定。

**停損實驗**（全部 ≤ 20 GPU 小時；原論文沒找到公開程式，需要自己重寫，但模型極小，單張 GPU 甚至 CPU 就能跑）
- **步驟 0，重現**：照附錄 E 的設定，跑 5 個 seed，追蹤「各 query 對 token 1 的平均注意力」A₁(t) 和 γ 的軌跡。
  - 判準：至少 4/5 個 seed 出現「A₁ 上升到峰值，之後在 loss 仍下降時，從峰值回落至少 30%」。做不到就停。
  - 另用全批次 GD 或 SGD 小步長跑一次，確認現象不是 Adam 造成的。
- **步驟 1，變體**：
  - 變體清單：H ∈ {1, 2, 4, 8}；LN ∈ {無, embedding 後加 LN, RMSNorm, 有無 gain}；層數 ∈ {1, 2}，有無殘差。
  - 每組 5 個 seed，ε ∈ {1/m², 1/m^1.5}，lr ∈ {×0.5, ×1, ×2}。
- **繼續的判準**：某個變體出現「質變」，例如稀釋消失、方向反轉、聚焦延後超過 2 倍，或各頭明顯分工，而且在至少 4/5 個 seed、所有 ε 和 lr 下都成立。
- **停止的判準**：
  - 所有變體都和單頭單層一樣：理論只是平凡推廣，價值低，停。
  - 變體結果隨 seed 或 lr 不穩定：難以寫成定理，停。
- **步驟 2（選做）**：TinyStories 上 1–2 層、有無 LN 各跑一次，看 A₁(t) 對高頻 token 的曲線，約數 GPU 小時。

## 4. 可檢驗的反直覺預測，以及文獻中的對立說法

**預測**
1. **LN 在秩一階段壓制、甚至消除 frequency 驅動的聚焦與稀釋**：理由見上，是我的推導，未驗證。
2. **多頭時各頭先完全同步聚焦，分工要等到資料不對稱（δ）出現才開始**：分工的時間尺度可能和定理 3.9 的 Θ(δ) 有關。這是推測。「先同步後分工」的現象 A 已提出，新意只在和 δ 掛鉤。
3. **ViT 上的版本**：patch 不是有頻率的離散 token，原機制很難直接搬過去，我認為預測力弱。
   - 已知 high-norm token／register 的現象出在大模型、訓練中後期：Darcet 的 DINOv2 據二手評論約在訓練 1/3 處出現（未讀原文）；2602.22394 的摘要也這麼說（只看到搜尋摘要）。
   - 這和小初始化、早期階段的分析不在同一個尺度，硬接上的說服力有限。

**對立或競爭說法**
- **E（2603.06248）**：梯度流單調地把 softmax 推向低熵，和「先聚焦後稀釋」直接衝突。差別可能來自他們沒有同時學嵌入；原論文的稀釋正是嵌入重分配造成的。
- **Zhai et al. 2303.06296（σReparam）**：訓練中注意力熵會崩塌；不過該文也說標準語言模型訓練沒看到崩塌（只看到搜尋摘要）。
- **2410.01380**：搜尋摘要說預訓練中「熵單調下降」，但該文的熵可能是指 FFN 記憶係數，不是注意力，未確認。
- **Wu, Ajorlou, Wang, Jegelka, Jadbabaie 2405.18781（NeurIPS 2024）**：在特定 value 矩陣下，LN 能讓注意力不必塌縮到秩一（可有各種秩的平衡點）。這支持「LN 會改變動態」，但他們談的是深度方向的前向動態，不是訓練動態。
- **D（Chen & Luo）**：已把凝聚連到 rank collapse，所以「連到 rank collapse」這個賣點的新穎度有限。
- **用語衝突**：AdaRoPE（2607.19363）等長上下文文獻把「attention dilution」用來指序列變長時注意力變平，和本文意思不同，寫作時要區分。

## 5. 總評

- **新穎性風險：中**。
  - 目前沒查到被做掉。
  - 但這是原作者在 Limitation 節自己點名的方向，該團隊（Xu／Luo）產量很高，8 月剛出相關的 C，很可能也瞄準 ICML 2027，撞期風險偏高。
  - 多頭方向另被 A、B 部分覆蓋，所以多頭的新穎性風險是中偏高；LN 方向是中。
- **可行性風險：高**（兩層）／**中偏高**（多頭、LN）。
  - 原論文附錄很長（HTML 全文約 20 萬字元），用到不變流形、Lyapunov–Schmidt 和遍歷性論證，定理 3.9 也只做到 d = 3。
  - 對數學能力中等、非理論專業的一到兩人，10 週要寫出 ICML 等級的完整定理很吃緊。
  - 比較實際的目標是「一個 LN 下的命題（秩一階段聚焦被壓制）加小實驗」。但這個規模可能被審稿人看作增量，題目夠不夠撐一篇 ICML 存疑。
  - 建議先做步驟 0 和步驟 1 的停損實驗再決定。
