# 正常學習率的獨立加密量測

在同一模型、訓練語料與正常學習率規格下，換一組訓練種子並加密取樣。驗證單步損傷的事件覆蓋、既有診斷以外的 attention 寫入訊號，以及四個局部介入距整步回退參考的差距。[前一面板](../gate-optimizer-nominal/PREREG.md) · [第三輪](../gate-optimizer/round3/PREREG.md)

- 固定前兩輪 OpenWebText shard 與 tokenizer、模型、三個 optimizer、base LR、100 步共享前綴及 400 步正常 cosine continuation。以 SHA-256 `gate-optimizer-nominal-dense-v1:<0–95>` 的前四個位元組取低 31 位元作 96 個新種子，檢查與先前校準、驗證及第 3 輪互斥。每個 seed 重設訓練順序，同 seed 的三個 optimizer 使用一致的訓練窗口及量測窗口。
- 每個分支在第 **22、24、…、400** 步，使用互斥的訊號及結果窗口，沿用原探針和 `0.05 nats` 損傷門檻。共 **288 個分支、54,720 個更新探針**。每個分段用第一個種子的三個 optimizer 與未加探針的訓練結果比對。學習率逐步相同且所有 dev NLL 差絕對值 ≤0.01 nats 才判讀，CPU 合成測試另強制觸發每筆局部介入並核對完全相同的訓練 trace。任何缺漏中止整批判讀。
- 保留原面板門檻（≥4 次損傷、≥2 個 seed、≥2 個 optimizer），另以種子為單位配對重抽 10,000 次（seed `202611151437`），報面板每探針事件率及有事件時的百分位 95% 區間。事件率適用於這個步距、資料與種子分布。達 ≥30 次損傷、≥6 個留出 seed 同時有正負例才量固定 ridge 及既有診斷加寫入後的等權增量 AUROC（+0.03 門檻），沿用以可評種子重抽的描述區間。驗的是步後偵測。更新量和 attention 寫入取自同一次更新，所有特徵均與結果窗口的 NLL 隔離。三個 optimizer 以整個 seed 一起留出，標準化及 ridge 只用其餘 seed。覆蓋不足保留事件數與事件率。新面板單獨判讀。
- 對每個事件保留四個局部介入和整步回退參考。在同一結果窗口用原同量守門與局部回收比例。比較限於單步已發生的事件，正常排程的等品質速度需另行量測。

八個分段各 12 個種子，單次只執行一段。沿用離線權重及語料配置，不下載檔案。根據前一面板的正常訓練與加密探針量，估全批 **2–4 GPU 小時**，每段上限 1 小時。保留探針與摘要估 **小於 80 MiB**；分段語料暫存約 0.04 GiB，完結清理。分段均成功且收據核對通過後，CPU 可產生彙總。
