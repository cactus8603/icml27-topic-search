# 資料歸因補空間訊號的獨立確認

原 Stage 0 的補空間訊號已量測，判為灰區。這次以同一投影定義、同一訓練軌跡及 50 個不同查詢重驗，檢查低成本歸因在精確量測子空間以外是否仍有可辨識訊號。原 Stage 0 和 seed 5 的跨種子條文照原登記判讀。 [原訊號判準](../../../killtests/multifidelity-attribution/PREREG.md#5-階段-0-的現象訊號與空間k50m200)

- 固定 seed 0、原 CIFAR-10／ResNet-9、原精度、資料與查詢排列、原 1% 移除重訓遮罩 `j=0..199`。用原排列的 `[50,100)` 零起算位置，整段 50 個查詢。這些位置的廉價分數與重訓檔已存在，尚無該批精確歸因，且不重疊先前精確診斷的 `[0,50)`、`[118,124)`、`[268,274)` 與 `[400,448)`。
- C 固定為原最佳 `ekfac_1e-8`，不在新查詢重選方法。從這 50 個查詢的原全參數梯度 Gram 子矩陣取前 10 方向，按照原 Stage 0 公式算互補殘差餘弦。置換按照原 seed 重新擬合純量混合，要求 `|rho_perm| ≤ 0.05` 且 `LDS(置換 Hybrid) − max(LDS(Spell), LDS(置換 EK-FAC)) ≤ 0.01`。任一不合格記為量測無效。常數排名或零範數使原始與置換餘弦或 M1 的三個 LDS 未定義時，保留位置並記未能測試。其餘方法的 LDS 若未定義，只將該描述統計留空。
- 按原訊號線，點估至少 0.20 且 95% 查詢重抽區間下界大於 0.10 時通過，區間上界低於 0.10 時未通過，其餘為灰區。區間使用原 10,000 次百分位重抽、seed 0，推論範圍限指定軌跡和既有重訓遮罩。另描述新查詢上原純量 Hybrid 和固定 EK-FAC 的 LDS 差。
- 正式計算前核對原資料與所有來源雜湊。用原程式重播 `[0,10)`，要求 loss 的標準化 RMSE 小於 0.02，且完整 metagradient 在同一個歷史檔案下的相對 L2 誤差小於 0.02，再計算五塊新精確查詢。單張 H200，正式時間上限 2 小時，保留約 12 MiB。分開寫入 `icml/runs/multifid/signal-confirm/<job-id>/`。封存版本執行完成後才讀彙總並登記。
