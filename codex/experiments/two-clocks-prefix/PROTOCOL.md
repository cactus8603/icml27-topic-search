# 兩個時鐘正對照的早期評估點診斷

第 2 週正式評估 `26383` 已完成。u833 的 15 對中有 7 對在第一個評估點達到最小值，超過 5 對的有效性限制。正式 n/K 正對照維持「未能測試」。這個診斷只量較早的評估點能否解釋此情形，沿用原資料、模型與曲線定義。它使用已知的七對正式彙總作事後核對。

- 只重播 u833 的六個原種子，沿用正式版 `9e92804` 的資料與訓練器，以及原執行所用外部 timestep embedding 提交 `df08bc6`。在暫存副本中只改停止的 epoch 與存檔點，Adam 的排程長度仍為 20,000，CUDA BF16、seed、batch 85、class-only 0 和 dropout 1.0 維持原值。
- 每次重播到 epoch 36，存 epoch 1、2、4、8、12、18、24、30、33、36。每一個 pick 先與現有第 30、33、36 點比整檔 SHA-256，檔案不同時比對張量 dtype、shape 與精確值。任何一點不符就停在重播檢查，連同停止原因寫成 JSON。
- 全部吻合後，在只讀原權重的獨立目錄中以原評估器算較早的七點與原完整 71 點。使用原評估種子 123、八個擴散時間、類別 0 的前 700 筆、訓練資料區塊 0–5、留出資料區塊 7，分支為無條件。每個擴散時間各自按整條所用網格的平均正規化，原遮罩、3 點平滑、後續上升 10% 及內部最低點規則照舊。
- 先從此次新算的結果抽出原有網格，只有原始第一點的配對集合與已發佈的七對彙總相符，才回報擴充網格。輸出兩種網格的分類計數、原第一點配對的重新分類，以及有內部最低點且落在 epoch 30 以前的對數。前七點的新增間距屬本探索設計。此結果不判整個 n/K 機制，不改正式訊號或入池決定。
- 另外保留原網格每對、每個擴散時間的正規化分母，在擴充網格使用同樣的遮罩、平滑與最低點規則重算一遍，分辨換正規化權重所致的變化。程式驗證這套分母在原 71 點還原未平滑的正式網格曲線後才回報。
