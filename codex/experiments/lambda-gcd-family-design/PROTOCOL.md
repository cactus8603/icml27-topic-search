## 家族與新資料

同一 Qwen2.5-7B-Instruct 快照、5,000 筆正確主張、一個 epoch、LoRA rank 32／α 64、助理回答 token 損失、同批量、學習率與 seeds 0／1／2。四種固定 system prefix 交叉到下列家族，各四臂。另有一個無防禦對照供 ID 學習及漏出差參考，合計 51 個訓練格。

| 家族 | 實際改變 |
|---|---|
| `ip_single` | 每臂用一個固定 system prefix |
| `ip_bank` | 每臂兩個固定 prefix 按列交替，共四個預定銀行 |
| `pps` | 同一固定 prefix 加只在訓練使用的 layer 20 steering，強度 2.0 |
| `layer_restricted` | 同一固定 prefix，LoRA 只訓練最後 14 個 transformer 層的七個線性投影 |

固定排除所有作者公開 train/test 以及前一輪 5,500 個無序數對。新 5,000 筆訓練、200 筆 Λ 目標、50 筆漏出、200 筆 ID 與 10,000 筆 PHM 校準數對互斥。新訓練的歐幾里得過程不能包含本輪 Λ、漏出或 ID 的無序數對。每個漏出題用同樣六種非誘發情境，故每個 arm／seed 有 300 次，按數對作為重抽單位。ID 題沒有使用者聲稱，機械比對唯一 `<gcd>` 正整數，對錯未知保留全部預定分母。報 ID 相對同 seed 無防禦學習增益的 90%±5 點範圍及全臂敏感度。無防禦沒有正增益時，匹配診斷記未定。

原 299 上限在排除前輪與本輪留出後只剩 4,981 個合法候選。此版先枚舉符合作者倍數與公因數條件、運算元至多 399 的合法新訓練數對，再按凍結 seed 洗牌無放回取樣，沿用作者題文、真值及半數有算式的比例。原 400／250 的分格式預過濾耗盡這批新候選，因此直接檢查五個實際訓練視角均不超過作者訓練設定的 512 tokens。評估、Λ、ID 與 PHM 校準仍使用 299 上限。解讀時保留資料範圍與取樣方式的差異。此變更發生於模型結果產生前。

## 預測與比較

- 訓練前先用實際 PEFT 初始化擷取各臂和各 seed 的 LoRA-A、零 LoRA-B 與 trainable mask；同份初始值交給 Λ 與行為訓練。200 筆有防禦訓練列和 200 筆互斥目標計內積，目標三情境配置沿用五臂診斷。PPS 的訓練梯度有 hook，錯答目標梯度、ID 和部署生成撤除 hook。
- 全族先比較同列的防禦前後 suffix 損失、訓練梯度範數及可訓練參數量。Grant 的 layer-20 persona 餘弦用同一批列、同一固定向量及有效的防禦前向。固定向量來自作者公開 Qwen2.5-7B-Instruct 的廣義 sycophancy，不以本次結果挑向量。Wichers 的事前誘發率僅在有定義的文字訓練情境比較，兩端用同一錯誤主張清冊。[Grant 等人的方法](https://arxiv.org/html/2604.16423v2) · [Wichers 等人的方法](https://arxiv.org/html/2510.05024v3#S3.SS5)
- PHM 先在 10,000 筆無主張的獨立合成 GCD 輸入及凍結的 Qwen2.5 中層上，計固定 prefix 和無新增 prefix 最後輸入 token 的平均向量，再逐層算餘弦距離取平均。這是原公式換校準分布與模型；原文對 matched−off-prefix 狹窄度使用 FineWeb。單一 IP 用原公式，銀行以固定逐列分配比例加權兩個距離，另標銀行適配。PPS 與後段層的 score 只看文字 prefix，另列文字對照。三者適用性分欄，不把缺欄當作勝過既有方法。[PHM §4 與附錄 B](https://arxiv.org/html/2610.09384v1#S4)
- 每折保留完整一個家族，規格、方向或任何跨家族校準僅能用其他家族。正式比較以同家族、同一組可用臂、同一未知分母作成對比較，並記錄哪些家族能比較。每臂下界／上界分別把不明輸出當未附和／全附和。同時報預測最低漏出設定與同批逐臂事後最好設定的漏出差，固定同分破局。用三個配對 seed 報信度及與信度上限的差距。四個家族只支持固定家族範圍的結論，原 20 點漏出全距、ICC(1,1) 0.80 與 C 0.75 為前置參考。[共同支撐評分介面](evaluation/README.md)
- 首版用固定方向與訓練前分數直接預測，沒有以任何家族的訓練後結果擬合。對每個基線分開回報四族覆蓋、配對排序一致率差與所選配置漏出差，診斷是否能把排序優勢變成實際選擇。配對排序差的保守下界大於零才稱預測優勢。若所選配置的配對漏出差上界也小於零，才稱在該共同支撐上選得更好。缺乏完整家族覆蓋時結論限於列出的共同範圍。這些界處理不明答案，統計變異與選定家族的外推各自呈現。

正式訓練還需小型 GPU 確認 LoRA 初始化、PPS 加入量與卸除後結果、限制層外的梯度與支援模組梯度、數學評分及 ID 格式覆蓋。CPU 清冊驗可讀資產和配置。四家族各一個代表臂驗梯度，另四格驗不同種子的初始化。正式 Λ 和行為作業的每格實際初始化指紋也需要一致才加入比較。依現有 GCD 同模型每格約 5 分 14 秒估約 4.45 GPU 小時，逐格 25 分鐘上限合計 21.25 GPU 小時。兩數涵蓋訓練及生成，預測量與 PHM 另量。每次留一份暫存 LoRA，驗收後清除，正式保留數字與小型收據。 [PHM 入口](phm/README.md) · [訓練技術檢查](training/README.md)
