# ICML 2027 選題與實驗

這個專案用小規模實驗篩選九個研究題目。我們先確認問題量得到，再檢查有沒有可用的訊號，以及現有方法還能改善多少。

每題各有一頁。介紹卡用例子說明問題，設計卡列出對照、最新結果、下一步和所需資源。信心與潛力各以 1–5 分表示研究判斷。信心看目前證據，潛力看關鍵驗證通過後能支撐的研究貢獻。
