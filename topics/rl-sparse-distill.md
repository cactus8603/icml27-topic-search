# 只移植少數 RL 推理決策的蒸餾

## 介紹卡

**要解的問題。** 強化學習（RL）調過的模型可能一次就比較容易答對。多給幾次機會時，基礎模型有時更容易找到不同的正確解法。這題想把 RL 有用的少數決策交給基礎模型，保留兩種表現，最後蒸餾成一個可單獨使用的模型。

**例子。** 同一道數學題，RL 模型可能第一步就選「因式分解」，基礎模型卻想「逐項展開」。讓兩條回答共用相同開頭，只替換第一個不同的文字單位，再由同一個基礎模型完成，可以測量這一步對答對與作答長度的影響。

**怎麼看表現。** `pass@1` 是模型作答一次的成功率，`pass@64` 是作答 64 次時至少有一次正確的機率。蒸餾是把混合策略的行為交給一個學生模型，部署時只需用它作答。 [正式設計](../killtests/rl-sparse-distill/PREREG.md)

**成功的樣子。** 同樣的取樣條件下，保留原 RL 至少一半的單次答對率增益，且多次嘗試比單用 RL 更有效。在相同 `pass@1` 還要能超過權重內插 WiSE-FT 的前緣。

## 設計卡

1. **量現象。** 固定題組、提示和 3,000 token 預算，找一對截斷率相差小於 2 點的模型。要求 RL 的 `pass@1` 高至少 5 點，而基礎模型的 `pass@64` 高至少 2 點。
2. **量訊號。** 在兩個模型偏好的下一個 token 不同時測少量替換。正式要求相對同引擎 RL，`pass@64` 增加至少 2 點且信賴下界大於零，同時守住 `pass@1` 保留比例。另用同一前綴、同一續寫模型的單 token 分叉測局部效果。 [正式訊號判準](../killtests/rl-sparse-distill/PREREG.md) · [局部分叉](../codex/experiments/rl-fork-budget/PREREG.md)
3. **量空間。** 在相同 `pass@1` 下，比較 token 替換、回應混合與 WiSE-FT。另用已知答對與否後逐題選模型，估計固定候選內的事後上限。 [原取樣的上限診斷](../codex/experiments/rl-gate0-censoring/PREREG.md)

**目前現象。** 外部 32K 資料中，RL 的 `pass@1` 高 **7.60 點**，`pass@64` 低 **1.30 點**，有表現交叉。原 3K 配對的兩端截斷仍不可比，短預算正式資格未過。 [外部重現](../codex/experiments/rl-external-passk-local/PREREG.md) · [短預算對照](../codex/experiments/rl-a-short-stop/PREREG.md)

**目前訊號。** 新 128 題的單 token 分叉多答對 **34.38 點**。把相同續寫預算由 3,000 拉到 3,710 tokens，兩臂仍分別有 55 和 6 題截斷。將截斷答案視為未知後，增益可能介於 **−8.59 至 +39.06 點**，局部效果能否排除截斷影響仍未定。 [延長預算讀取紀錄](../codex/experiments/rl-fork-budget/PREREG.md#讀取紀錄)

**目前空間。** 新分叉的最佳固定選法是 86/128，兩候選事後選正解可達 89/128，差 **2.34 點**。原 3K 固定模型在同 `pass@1`、同取樣次數下，事後選模型可多 **3.68 點** `pass@64`。這是已知答案時能做到的改善幅度。 [分叉上限](../codex/experiments/rl-fork-budget/PREREG.md#讀取紀錄) · [原取樣上限](../codex/experiments/rl-gate0-censoring/PREREG.md#讀取紀錄)

**下一個判定。** 先取得截斷率可比的新配對。用同樣算力看少量 token 替換能否帶來多次作答的增益，再決定是否訓練學生模型。 [正式決策條件](../killtests/rl-sparse-distill/PREREG.md)

### 信心、潛力與資源

- **現有證據 2/5，條件式論文潛力 3/5。** 局部分叉有效果，仍受截斷影響。若新配對能在同樣算力下實際改善多次作答，才值得蒸餾成單一模型。
- **下一步資源估計。** 核對一組新候選的權重、模板與參考結果估 **半天到一天**。若能沿用 3,000-token 規格，正式資格測試原估每組 **5–7 H200 GPU 小時**，按單卡依序執行約 **5–7 小時**，不含排隊與前置核對。原長批取樣配置申請 **170 GiB RAM**。作為實測參考，已完成的單步分叉用了 **1 張 H200、44 分 33 秒、3.73 GiB RAM**，收據約 **87 KiB**。 [正式資格預算](../killtests/rl-sparse-distill/PREREG.md) · [取樣資源](../killtests/rl-sparse-distill/slurm/01_vllm_sample.sbatch) · [分叉實測](../codex/experiments/rl-fork-budget/PREREG.md#讀取紀錄)
