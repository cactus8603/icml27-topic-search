# 同分次鍵的 CPU 合成檢驗

26582 已用一維高斯確認同分的估計問題。這次比較原分數與只在同分組內增加次鍵，所有臂一律使用二維獨立標準高斯 `(Z, W)`。目標事件維持 `Z ≥ c`，其中 `c = Φ⁻¹(0.999)`，真率為 0.001。固定 32 個新種子 `[2026111640, 2026111672)`，與 0–3 先導、已閱 `[2026111550, 2026111582)` 和 26582 的 `[2026111600, 2026111632)` 互斥。每個種子跑全七臂，重設同一 RNG 並逐位元配對初始二維高斯樣本。各臂的接受與排序可使後續鏈位置分歧。 [26582 固定分數定義](../t2i-tied-scores/PREREG.md)

令 `U = Φ(W)`。在精確算術下，U 是獨立於 Z 的均勻分布。原始七臂中的四個原分數以同一二維輸入執行，其中連續分數是參照。其餘三臂各給同分組獨立次鍵。

| 分數 | 原分數 | 次鍵規則 | 同一事件的門檻 |
|---|---|---|---|
| 連續 | `Z` | 參照 | `c` |
| 單調量化 | `floor((Z − c)/0.25)` | 每個分數 `k` 編碼到 `[k, k+1)` | `0` |
| 大量零分 | `max(0, Z − 2)` | 零分編碼到 `[−1, 0)`，正分原值 | `c − 2` |
| 二元 | `1[Z ≥ c]` | 每個分數 `k` 編碼到 `[k, k+1)` | `1` |

每個區間以 `min(k+U, nextafter(k+1, k))` 編碼，防止 CDF 或相加浮點捨入到下一級。飽和時仍可能在組內同分。唯讀預檢用解析尾率、`c` 兩側的浮點鄰值和不同副座標驗證事件，獨立 fixture 也覆蓋 CDF 接近 0 或 1、跨組排序與組內次鍵。

沿用未改動的 SuS v2、`N=1000`、`p0=0.1`、MCMC 4、初始步長 0.5 和最多 30 層。逐臂報有限筆數、耗盡筆數、呼叫數及層數；全組有缺值時，偏差只列於有限子集。每個原樣/次鍵配對另報雙方有限數及其平均估值差除以真率、全部種子的呼叫差中位數，以及原臂耗盡而次鍵回有限值的種子數。原臂全耗盡時配對估值差留空。單一 CPU 工作上限五分鐘，輸出一份小型聚合 JSON。這個研究只適用於已知真值的合成設計，原正式 a′、Gate B 與文生圖判準仍依原預登記。 [原 SuS 設計](../../killtest/PREREG.md)
