## 候選池與關聯標註

- 使用已鎖定的 COCO train2017 和 val2017 官方 instances 標註。依既有面板清冊排除已用及已排除影像、同一 Flickr 來源、validation 圖與 Half-Truths 的已知影像。以原 seed `2026111541` 的雜湊次序從剩餘 train2017 取 8,192 個候選。排除曾建立或評過的類別配對。
- 每個物件使用非 crowd、面積至少占畫面 2% 的標註。雙物件都符合的影像是正例，兩側各有至少一張只符合單一物件的影像才保留該查詢。用整個驗收池重建正例分母，按固定原規則分群。
- 取得 JPEG 後須核對標註尺寸及可解碼性，排除與舊資料和本池的位元重複。最終面板至少需 8,110 張圖、100 條互斥查詢與 85 群。完整清冊綁定逐圖雜湊以及查詢文字、相關影像、群碼的固定順序。標註候選清冊可先重算。實體影像及最終覆蓋驗收完成後才可提交排名推論。

## 排名收益與上限

- 凍結 `26806` 的兩種入口。分別取 CORE 前 50 名、依名次交錯 CORE 與 CS-CLIP 去重後的前 50 名。兩臂每查詢各用 50 次同一交叉編碼，重用共同的分數，尾序保留同一 CORE 相對次序。交錯臂另計一次全池 embedding 的成本。
- 以同一最終池的全池 mAP 比較差值。按固定查詢群重抽 10,000 次，沿用原 seed `2026111591`。點估至少 +2 個百分點且 95% 下界大於零才支持繼續。上界低於 +2 個百分點記未達原定幅度，其餘未定。
- 報各臂 Recall@50、零正例入選的題數，以及固定名單與尾序、名單內正例事後排最前的 mAP 上限。比較各臂實測至各自上限的差，並照實列候選入口增加的計算時間。基線在新面板獨立計分，驗收清冊、全池排名及共同分數一致性。 [舊面板的估計器](../retrieval-recall-budget/score.py)
