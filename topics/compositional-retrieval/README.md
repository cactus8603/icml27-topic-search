# 多條件影像檢索

## 介紹卡

**研究問題**　搜尋句子有好幾個條件時，影像檢索系統能把每項都符合的圖片排到前面嗎？

**例子**　你想找「紅杯子在盤子的左邊」。紅杯子在盤子右邊的照片只有位置不符。只有紅杯子而沒有盤子的照片則少了另一個物件。好的搜尋結果會把完全符合的照片排在這兩張前面。

**怎麼看數字**　同圖三句排序正確率（COR）要求模型對同一張圖給「全對的描述」最高分、「只描述已確認內容的短句」次高分、「加入錯誤細節的描述」最低分。跨圖檢索則看前 50 名涵蓋多少標註相關圖（Recall@50），以及排名前段有多集中是相關圖（mAP）。mAP 先在每條查詢的相關圖名次計算從榜首到該名次的精確率，再對相關圖及查詢取平均。
