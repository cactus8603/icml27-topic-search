# 多條件影像檢索｜設計卡

**假設**　若不同索引模型漏掉的相關圖片不同，讓兩個索引共同決定入池圖片，可在同樣 50 次精細重排下提高全庫 mAP。

**資料與對照**　用原大圖庫的 8,191 張圖與 136 條雙物件查詢。基線取 CORE 整句分數的前 50 名，試驗組交錯取 CORE 與 CS-CLIP 的排序，去重後同樣選 50 張。兩組用同一個 CORE 重排器，試驗組另付一次全庫向量搜尋的成本。[召回與重排協議](code/experiments/retrieval-recall-budget/PREREG.md)

**主量與門檻**　同一條查詢配對比較全庫 mAP，按原查詢群做區間估計。預先要求 mAP 至少提高 2 個百分點，且 95% 區間下界大於零。

**診斷**　一起看 Recall@50、前 50 名全無正例的查詢數，以及把既有名單內標註正例全部移到前面可得到的 mAP。三項可看出落差出在候選漏找，還是已入池的圖沒有排好。
