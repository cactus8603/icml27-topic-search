# 大型平行解碼提交集合

**暫停**（2026-11-15）

## 介紹卡

擴散式語言模型可以在一輪填入多個空位，減少需要執行模型的次數。「提交」是把選中的位置及內容定下來，模型接著依已填的內容續寫。這題研究同一輪該選哪些位置，兼顧速度與答對率。

想像模型在填「□ × □ = 12」。左格的 3 和右格的 6 各自都合理，因為它們可分別出現在 3 × 4、2 × 6。把兩個提案同時填入就會得到 18。逐格的高信心可能漏掉這類組合衝突。

研究要找的是在鎖定一組詞之前，可用來選擇整組候選的訊號。評估時看選完並續寫後究竟答對幾題，也計入取得訊號所需的模型運算。
