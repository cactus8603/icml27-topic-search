# 以新遮罩重驗多保真歸因的排序收益

本試驗固定 `26734` 的 50 個查詢和所有預測設定。只重抽訓練集移除遮罩，檢查 Hybrid 能否改善同一訓練軌跡上的實際重訓排序。原 Stage 0、保留的 seed 5 和正式跨種子 `H_x` 依原協議判讀。 [50 查詢訊號檢查](../multifidelity-signal-confirm/PREREG.md) · [原正式協議](../../killtest/PREREG.md)

## 固定查詢、預測及重訓

- 原 CIFAR-10 排列零起算 `[50,100)`，訓練 seed 0。Exact 取 `26734` 已完成的五塊精確歸因。EK-FAC 是同軌跡已固定的 `damping=1e-8`，十個方向取這 50 查詢的舊 Gram 子矩陣。Spell 與 Hybrid 使用 `26734` 的同一投影和子空間純量擬合。兩者的矩陣運算、方向和擬合不讀新遮罩重訓結果。重用全精確手段只作排序參考和離線模擬十方向量測。
- 保留原 `mask_seed=1234` 與每列 1% 的獨立移除規則，固定全新遮罩 `j=456..519`。原 Stage 0 與 `26734` 用 `0..199`，方向覆蓋用 `200..327`，`26654` 用 `328..391`，`26703` 用 `392..455`。CPU 預檢驗整段 `0..519` 的 packed 遮罩皆互異、歷史與新遮罩的 SHA-256 及 `26703` 已登記的末段遮罩指紋。
- 原訓練與預測公式取 `599469e3faf5dec7aae854cc929c6d265bdd706f`，採全 50,000 CIFAR-10 訓練例、ResNet-9 W=80、SGD＋momentum、20 epochs、batch 500、原增強及 JAX 精度。逐遮罩以權重歸零移除，保留 `26703` 的原 400 查詢前向形狀和排序，只保存 `[50,100)` 的交叉熵。正式重訓前重跑歷史遮罩 `100/101`，各在全 400 查詢的 RMSE 除以 `max(std(reference), 0.1)` 須小於 `0.02`。兩個歷史遮罩只作技術核對。 [重訓參考](../multifidelity-transfer-lds/PREREG.md)
- 清冊核對原資料、程式和環境版本、`26734` 的完成及已驗收摘要、精確矩陣、EK-FAC、Gram 和重播來源。CPU 預檢用原 200 個遮罩且只讀已公開結果，重算先前摘要所列六個 LDS，逐一允許絕對差不超過 `1e-8`。任一來源、查詢順序、舊 LDS 或技術重播不合即中止。

## 評分及判讀

- 沿用原 float32 移除列總和取負值。逐查詢跨 64 遮罩做平手平均排名的 Spearman，再取 50 查詢等權平均 LDS。主要差值為 Hybrid 減 Spell／EK-FAC 中平均較高者，另外報兩個各自差值、Exact 距 Hybrid 與 Exact 距全組最強非精確法。最強法按各方法的整組均值決定。
- 用 `default_rng(0)` 先產生 10,000 組成對查詢索引，再產生同規格的成對遮罩索引。報只抽查詢的描述性中央 95% 百分位區間，以及聯合抽兩軸的區間。聯合重抽對各方法使用相同遮罩及查詢索引，按被抽到的 64 個遮罩重新計算 Spearman。每次重抽都重取基線均值的最大值。兩種區間的範圍限於同一訓練 seed，以及此固定查詢與同種隨機移除規則。
- 負控制保持原固定同列置換 seed，重擬置換 Hybrid 的純量。置換 Hybrid 減 Spell／置換 EK-FAC 中平均較高者須 `≤0.01`，超過則判負控制未過，保留描述性分數。任一方法的固定面板有常數排名時，列不可評位置，整組主比較記未能測試。若只有聯合重抽產生未定義的差值，列有效重抽數，以下界代 `−2`、上界代 `+2` 取保守百分位。
- 以舊新遮罩診斷的 `+0.04 LDS` 為實用參考。Hybrid 對較強基線的點估至少 `+0.04` 且聯合區間下界大於零時記達參考；聯合區間上界低於 `+0.04` 時記低於參考；其餘記未定。參考幅度為排序收益判斷。Hybrid 與 Spell 都使用十個精確方向，Hybrid 另需 EK-FAC 與混合運算；完整方向成本和實際推論耗時另量。 [舊新遮罩診斷](../multifidelity-heldout-lds/PREREG.md)
