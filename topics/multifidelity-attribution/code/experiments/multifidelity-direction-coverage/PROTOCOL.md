# 多保真度資料歸因的新方向覆蓋試驗

這次檢驗在同一個十方向精確預算下，根據便宜代理的遮罩反應挑選方向，能否提高新查詢的留出遮罩線性覆蓋。上一輪 12 查詢的結果只用來提出問題。本試驗讀取固定來源、CIFAR-10 檔案和新運算產生的資料。

## 固定輸入與方向預算

- 沿用 `599469e3faf5dec7aae854cc929c6d265bdd706f` 的資料讀取、Stage 0 設定、ResNet-9 和 JAX 精確重播，使用 seed 0、50,000 個訓練列。先核對六個資料檔雜湊，從頭重播一次全權重訓練，所有精確欄共用該軌跡。正式輸出、既有模型、歸因與重訓快取均未列入輸入。
- 使用原查詢排列位置 `[400,424)` 的 24 個候選與 `[424,436)` 的 12 個評估查詢。位置從零開始。兩組與原 400 查詢互斥，無替補。固定種子生成 `[200,264)` 的 64 個擬合遮罩與 `[264,328)` 的 64 個留出遮罩。與原 200 個遮罩使用相同的 1% Bernoulli 移除機制。
- 均勻對照以 PCG64 seed `7611501` 從 24 個候選不重複抽十個。幾何組以全權重模型的最後線性層交叉熵梯度內積為便宜代理。以 64 個擬合遮罩將訓練樣本分數合成每個候選的遮罩反應，逐欄中心化並除以 L2 範數，以最大殘差範數貪婪地挑十個欄位。`1e-10` 內的同分取較早候選。兩組各使用恰好十個精確查詢欄，兩組重疊的欄位共用一次重播計算。同時保留 12 個完全獨立的查詢作評估。
- 選擇收據 `selection.json` 在第一個精確查詢前寫入，記錄兩組選擇、凍結 commit、候選和評估位置、遮罩分割、輸入雜湊與實際運算環境。兩組的選擇均不使用目標查詢或其結果。任何重試使用新的 Slurm job ID 並保留原收據。

## 唯一比較與判讀

令 $M$ 為負移除指示值，$Y_A$ 為一組十個精確方向，$Y_t$ 為十二個評估查詢的精確梯度。對兩組分別以擬合遮罩的 $F=MY_A$（含截距）預測 $E=MY_t$，再在同一批留出遮罩評估。用擬合資料中心化並正規化方向，最小平方相對秩門檻 `1e-10`。評分對每個查詢各自中心化 $E$ 與預測，再計算 $R^2$，與原精確診斷的遮罩變化度量相同。每組可用的擬合資料與精確方向數相同。

主要比較量是 12 個查詢逐一配對的 $R^2$ 差中位數（幾何減均勻）。PCG64 `7611502` 取 10,000 次查詢配對 bootstrap。中位差至少 `+0.10` 且 95% 區間下端大於 0 時記 `COVERAGE_IMPROVEMENT`，其餘有效量測為 `INCONCLUSIVE`。同時報兩組絕對中位數，正差仍可能伴隨偏低的絕對覆蓋。便宜選擇或精確擬合秩不足、非有限值、必要留出預測或目標為常數時記 `UNTESTABLE`。輸入、裝置與檔案驗證故障以執行失敗結束。

此處度量是使用精確目標擬合的線性空間能力，bootstrap 僅描述共享遮罩及單一軌跡下的 12 個查詢。實際排序（LDS）、可部署的目標係數估計和跨 seed 泛化均需另量。原 Stage 0 判定維持原規格。若下一輪要量測實際重訓排名，需另建新遮罩的重訓損失。以既有吞吐推估，64 個留出遮罩約 30–45 GPU 分鐘，若也要用實測校準再加 64 個擬合遮罩。

## 執行與空間

以一張 H200、8 CPU、96 GiB 系統 RAM、2 小時 Slurm 上限執行。`XLA_PYTHON_CLIENT_MEM_FRACTION=0.90`，先前相同精確重播量到含預留約 126.4 GiB。視方向重疊程度共計 22–32 個精確查詢，按先前同設定作業估約 45–65 分鐘。精確向量逐塊留記憶體，單塊最多 10×50,000 float32，結果只在共用空間 `icml/runs/multifid/direction_coverage/<job-id>/` 建立兩份小型 JSON。另留 Slurm log 與執行期間的小型來源快照。CPU 合成測試和資料雜湊檢查不需要啟動 Slurm。

```bash
pilot=codex/experiments/multifidelity-direction-coverage
PYTHONDONTWRITEBYTECODE=1 ../icml/envs/attrib-jax/bin/python -m unittest discover -s "$pilot"
freeze=$(git rev-parse HEAD)
bash "$pilot/run.sbatch" "$freeze" --check-only
# 完成審查並協調後執行
sbatch --parsable "$pilot/run.sbatch" "$freeze"
```
