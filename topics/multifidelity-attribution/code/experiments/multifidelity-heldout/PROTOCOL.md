# [codex] CIFAR-10 多保真度資料歸因：固定十個方向的內部留出測試

此 CPU 分析使用既有 ResNet-9 seed 0 產物。正式 Stage 0 結果與跨種子資格沿用原始判準。Stage 0 已公開前 50 個查詢、200 個遮罩的聯合彙總，故下述測試仍屬探索性。資料中精確歸因只有查詢位置 0–49，重訓損失、七個便宜方法、查詢梯度 Gram 則涵蓋位置 0–399。

## 固定切分

所有位置從 0 計數，採用既有 CIFAR-10 查詢排列 seed 20261114、遮罩 seed 1234、每筆移除率 0.01。用查詢 0–49 與遮罩 0–99 上平均 LDS，從原始七個方法選一個便宜方法 C。同分按原 criteria 陣列順序。主檢驗用查詢 50–399、遮罩 100–199。一開始就固定的敏感度分析使用四個查詢／遮罩切分格子，另將主檢驗遮罩等分為 100–149 與 150–199。選完 C 後，各格子沿用同一 C、方向與校準係數。所有格子共享 seed 0、50,000 個訓練樣本及其分數向量，分開的是重訓遮罩實現與查詢位置。前 50 個查詢上的遮罩留出仍承受已看過 Stage 0 彙總的影響。

## 十個量測與對照

令 J 為位置 0–49。先從對稱化的查詢梯度 Gram `G[J,J]` 取前十個單位特徵向量 U 及正特徵值 Λ。只向候選方法提供十欄精確量測 `A = Y[J] U`，每一欄代表一個線性查詢組合的精確反向量測；這裡從既有 50 欄離線模擬。測試及敏感度均共用這十欄。對任一目標查詢集 T，以可便宜取得的梯度 Gram 算 `D_T = Λ⁻¹ Uᵀ G[J,T]`（對校準集應等於 `Uᵀ`）。以 `C_J U` 和 A 的逐元素最小平方，估計共同係數 `α = <A,C_J U> / ||C_J U||²`。這一步使用全部訓練樣本列，但不用任何遮罩或重訓損失；只有 C 的模型選擇使用校準重訓損失。所有查詢及遮罩預測在評估前固定。

- 候選：`A D_T + α(C_T − C_J U D_T)`。
- 同十次精確量測的 Spell 式核延伸：`A D_T`。它在校準查詢上重現原簡化版 Spell 的投影。
- 原七種純便宜對照及校準選中的 C。它們用零次精確量測，作成本不高於候選的基線。Grad-dot 的 Gram 計算及所選 C 的額外成本均記錄在共用現有產物的假設下。這是等精確量測預算的比較，實際總算力待另量。
- 另記 `αC_T` 及 `α(C_T − C_J U D_T)` 的 LDS 作消融；後者共用 U 與 α，仍使用十次精確量測作 α 的校準。兩者均不納入主判讀的基線最大值。

除 A 之外，預測及模型選擇都不接觸完整 Y。查詢 50–399 的精確 Y 不存在。目標查詢的 Gram 交叉區塊和便宜分數可用於預測，重訓損失及精確歸因從未用作這些位置的校準標籤。原 50 個查詢的無移除損失用來核對檔案身份，並非估計器輸入。

## 指標、檢查與判讀

依原定義逐查詢計算 100 個遮罩的 Spearman `corr(−sum_{i∈removed} S_iq, loss_q)`，對查詢取平均。主增益為候選減去 `max(Spell 式延伸, 7 種便宜方法)`；另外列出對 Spell、所選 C、最佳便宜方法的差值。每個差值給相同測試查詢索引配對重抽的 95% 百分位區間（10,000 次，PCG64 seed 20261115）。主增益每次重抽皆重取基線最大值。區間的變異源為查詢，條件固定訓練軌跡與測試遮罩。遮罩切半單獨描述其敏感度。零秩變異、非有限分數、配對檔案不符均完整記錄並中止。

舊的 +0.04 LDS 作實用參照：點估計至少 +0.04 且區間下界大於零時，記為本次設定支持實用增益；若上界低於 +0.04，則本次設定下未達實用參照；其他情況記為不確定。任何結果皆為內部驗證，與外部重現、同 seed 全 Y 上限、跨種子 Stage 0 複驗為不同命題。

檢查原始陣列形狀與檔案雜湊、遮罩生成公式與 200 筆輸出排列、原前 50 查詢的 200 筆凍結重訓切片、精確區塊的基準查詢損失與主模型匯出、匯出參照的 checkpoint SHA-256 與查詢索引。要求精確重播、主 checkpoint、四次無移除重訓於這 50 欄具有相同秩序，另外記錄差值幅度。確認 U 正交、`D_J≈Uᵀ`、測得子空間的校準殘差約為零、α 最小平方正交條件。記錄 `A`、`A D_T` 與補值在測試遮罩上的絕對尺度及測試查詢相對梯度能量。原始矩陣無逐列識別欄位，故行列身份仍依凍結產生器、輸出命名和共同配置。
